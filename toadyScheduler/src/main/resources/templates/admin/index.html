수동 수집

과거 데이터 복원 또는 누락 데이터 재조회

가점만 복원하려면 ‘APT 당첨 가점’을 선택하세요. 전체 수집은 공고·주택형과 모든 결과 데이터를 순서대로 갱신합니다.

조회 기간은 모집공고일 기준입니다.

가점 발표일이나 청약 접수일이 아닙니다. 90일보다 오래된 공고도 기간을 직접 지정해 수집할 수 있습니다.

월별로 나눠 백그라운드에서 실행합니다. 이 페이지를 닫아도 작업은 계속됩니다.
